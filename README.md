# 喜欢搬家

把 QQ 音乐「我喜欢」迁到网易云音乐的系统红心列表。Windows 本地运行，支持人工补歌、断点续传和顺序核验。

- 两端扫码，重启后核验保存的授权。
- 高分自动匹配，低分可连续人工确认，也可粘贴网易云单曲链接。
- 写后读回确认，遇到中断可重新预览；安全合并保留原有红心。

**v0.1.12 预发布版。** 依赖非官方接口，建议先用少量歌曲试迁移。

## 启动

从 GitHub 仓库的 Releases 下载 `MusicBridge-v0.1.12-Windows-x64.zip`，完整解压后双击 `MusicBridge.exe`。必须保留 EXE 同目录的 `_internal`、`bridge`、`runtime` 文件夹；打包版不需要另外安装 Python、Node.js，不依赖 Codex。

从旧打包版升级时，先关闭两个版本，再把旧版 EXE 同级的 `data` 文件夹复制到新版 EXE 旁边。同一台电脑、同一个 Windows 用户可继续使用保存的授权、匹配和断点。请先保留旧目录作为备份。

若使用源码：安装 Python 3.11+（包含 Tcl/Tk，勾选 PATH）和 Node.js 22+ LTS。双击 `Start.cmd`，首次会创建 `.venv`、安装锁定依赖，需要网络。也可右键使用 PowerShell 运行 `setup.ps1`。安装失败时窗口会保留错误，不会显示虚假成功。

程序需要正常访问 QQ 音乐、网易云；平台可能调整私有接口，或要求在官方应用完成人工验证。遇到限制应停止并按平台提示操作。

## 第一次迁移

1. 点击右上角「使用指南」查看步骤，鼠标停在按钮上可看用途。分别用手机扫码登录两端。授权用 Windows DPAPI 加密存于本机。重开会在后台核验保存的授权；「已连接」就可以继续，「暂未核验」可用「检查连接」重查，只有确认失效才需要重扫。
2. 点击「读取并备份两端」。QQ 分页读取固定目录 201，按平台总数检查，不接受重复页或截断。完整读取两遍，确认顺序稳定。网易云用系统类型标记和所有者识别喜欢列表，使用 `trackIds` 获取完整顺序，分批补齐元数据，再与真实红心 ID 集合交叉检查。异常会停止，不能静默少读。
3. 对照 QQ 当前列表的首尾和中间位置。接口原序不被当成界面顺序保证。必要时「反转源序列」，然后「确认源顺序」，填写 QQ 当前排序方式。若界面按名称、自定义顺序等显示且与预览不一致，请先将 QQ 切换至与预览一致的默认收藏排序再确认；本版本不支持任意拖动来源排序。
4. 点击「搜索匹配 / 续查」。搜索关键词会去掉歌名末尾括号后缀（支持中英文括号、嵌套和连续后缀），每首搜索“简化歌名 + 歌手”和简化歌名，每种至多两页、共最多 120 个候选。原始标题和版本信息保留用于评分，现场、混音、翻唱等冲突仍会降分。最高分严格大于 0.8 时自动选定，不要求前两名分差。存在候选元数据缺失时仍需人工核对。旧缓存中尚未确认且带括号后缀的歌曲会补搜一次，保留旧候选和所有人工决定。
5. 点击「连续确认（数量）」打开独立窗口：左侧只列出待处理歌曲，右侧显示原曲及候选。没找到时，可修改「关键词」点击「自行搜索」，也可点击「下一页结果」继续查看；已有候选会保留并按 ID 去重。或在「链接 / ID」粘贴网易云歌曲完整链接或纯数字 ID，点击「读取并补充候选」，程序会读取真实元数据后选中该候选。支持 `https://music.163.com/#/song?id=...` 等歌曲链接；分享短链接需先用浏览器展开，歌单/专辑链接不接受。补充候选不会直接收藏或自动确认，选定后点击「确认选中 → 下一首」或按 Enter，立即保存并自动下一首。可跳过或稍后处理；关闭后再进入继续剩余歌曲。双击候选可打开官方歌曲页；双击主列表也可打开同样窗口，重新搜索或修改已确认、已跳过的单曲。搜索在后台执行，原有决定不会因网络失败丢失。
6. 首次点击「排序实测」。预览会列出两首**已匹配、尚未喜欢**的歌曲；确认后先备份，再实际新增两首验证置顶或置底。这两首会保留。可额外测试重排，只交换这两首的位置。新迁移的证据绑定账号，通常 24 小时有效；已开始的同一任务可以复用证据续传。
7. 选择模式并点击「迁移预览」。核对账号、匹配和新增顺序，再点击「确认迁移 / 续传」。每次批量写入都要确认。预览有效期 15 分钟。
8. 进度条显示当前写到第几首和本轮已读回确认的数量。「歌曲与匹配」中已迁移、已在网易云和明确不迁移的行会置灰。结束后在「预览与报告」看核验摘要，可打开完整报告查看漏歌、元数据和顺序差异。元数据核验无法证明音频内容完全相同。

## 两种模式的边界

- **安全合并（默认）**：仅新增缺少的歌曲，绝不取消任何原有喜欢。按账号实测的置顶/置底规则串行执行，保持新歌曲相对顺序。原有歌曲位置可能妨碍全部来源歌曲的相对顺序；报告分别显示新歌曲顺序和全部已匹配歌曲顺序，存在差异不会报完全成功。
- **按 QQ 顺序严格同步**：只有当前账号通过真实系统喜欢列表重排测试，且目标不存在来源匹配集合之外的额外喜欢时才开放执行。新增后请求整体重排，再完整重读验证。若有额外收藏或平台不允许重排，明确拒绝；不提供未经验证的批量取消/重新喜欢方案。它不会自动删除额外收藏，因此不保证所有账号都能严格同步。

不要在迁移中手动更改网易云喜欢列表。两次新增之间，工具在等待间隔结束后读取实时列表，用同一次读取核验上一首并检查下一首的写入前状态。观察到外部变化或未知排序会暂停。检测与写入之间仍有短时间窗口，同时发生的修改可能无法识别。

## 中断、续传与备份

批量迁移默认每次新增至少间隔 20 秒，喜欢列表查询至少间隔 12 秒。遇到 405 或 429，工具会依次等待 2、4、8、16 分钟再试，并将本轮后续写入间隔逐步延长到 30、45、60 秒。恢复后先核对实时列表，再继续迁移。若已经读到上一首，直接记为确认。只有平台明确拒绝写入且读回的列表与写入前完全一致，才会再次提交同一首。连续受限、授权失效或列表出现意外变化时会暂停。可点击「暂停」停止等待，正在提交的网络请求会先结束。每次请求前保存 `inflight`，重新读取确认后保存 `journal`。JSON 写入使用临时文件、flush/fsync 和原子替换。

重启后保存的来源、候选和匹配会恢复。**同一账号、来源和模式续传不用重新排序实测。** 点击「迁移预览」实时重读目标，排除已喜欢的歌曲，再点「确认迁移 / 续传」。严格同步仍会检查额外收藏。重新读取时，如果来源和账号没变化，会保留匹配；变更时会清除匹配与源顺序确认。

如果单首写入返回 500，程序会先读回核验；确认未加入就停在该曲。在「歌曲与匹配」选中出错歌曲（或点「定位出错歌曲」），点击「人工选候选」。在网易云音乐找到正确版本并复制完整单曲链接，粘贴到「链接 / ID」，点「读取并补充候选」，选中并确认后点「保存并关闭」。回到主界面重新预览，再确认续传。短链接可先在浏览器打开再复制完整链接。更多处理方式见应用内「常见问题」。

登录授权、歌单备份和迁移记录只保存在本机。源码版写入项目下的 `data/`，打包版写入 EXE 旁的 `data/`。请将程序解压到当前用户可写的目录。反馈问题时请先遮挡账号、歌单信息，勿上传整个数据目录。

| 路径 | 内容 |
|---|---|
| `backups/<时间>/qq.json、qq.csv` | 完整来源、固定序号、元数据、排序说明 |
| `backups/<时间>/netease.json、netease.csv` | 写入前网易云完整歌曲与顺序 |
| `confirmed-source/` | 你确认过的来源顺序 |
| `session.json` | 来源、候选、人工决策、排序证据、预览、断点和报告 |
| `reports/report-*.json` | 每次迁移结果与逐项差异、错误、未匹配候选 |
| `reports/target-final.json、csv` | 最近一次完成重新读取的目标元数据与顺序 |
| `authorization.dpapi` | 加密授权；不包含于报告和备份 |

备份不等于平台可恢复原收藏时间。点击「清除授权」会删除本机加密会话；不会操作平台收藏。要撤销其他设备的授权，请使用平台的官方账号设置。

## 验证与开发

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m compileall -q musicbridge tests main.py
```

Windows DPAPI 测试需要正常用户上下文。受限沙箱中可能因用户密钥配置不可见而失败；不会降级成明文。测试使用临时目录和假平台，绝不改真实收藏。

源码：`core.py` 管理匹配、备份、预览和核验；`providers.py` 适配 QQ SDK 与网易云本地桥；`gui.py` 用工作线程和消息队列保持界面响应；`vault.py` 负责加密授权。Node 桥只接受白名单功能，凭据经 stdin 传递，不开 HTTP 端口，不把 Cookie 放进命令行。

运行 `build.ps1` 构建 Windows 文件夹版。构建依赖在 `requirements-build.txt`，JS 间接依赖由 `bridge/package-lock.json` 锁定。生成 `Windows/MusicBridge/`，内含 Node 运行时。许可证及上游源码说明见 `THIRD_PARTY_NOTICES.md`。

测试覆盖和真实平台的边界见 [测试与限制](docs/测试与限制.md)。
